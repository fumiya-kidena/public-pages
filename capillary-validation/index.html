Viscous Fingering — 事前 Validation

単管毛管流：2流体系の Washburn 方程式

水平単管内を、粘性の異なる2つの非混和流体が入れ替わりながら進む問題（毛管現象）の解析解。VOFソルバの検証に使う。

0. セットアップ

重力・慣性を無視した準定常近似（低 Reynolds数・低 Capillary数）。メニスカス位置 $x(t)$ が $x{=}0$（毛管入口）から $x{=}L$（開放端）へ進む。

1. 力の釣り合い

Hagen–Poiseuille則（各流体区間の粘性圧力損失）とYoung–Laplace式（毛管圧）の釣り合いから：

$$\frac{2\sigma\cos\theta}{r} = \frac{8v}{r^2}\big[\mu_1 x+\mu_2(L-x)\big]$$

2. 速度（瞬間値）

$$v(x) = \frac{dx}{dt} = \frac{r\sigma\cos\theta}{4\big[\mu_2 L + (\mu_1-\mu_2)x\big]}$$

$\mu_1,\mu_2$：invading／defending 流体の粘性、$\sigma$：表面張力、$\theta$：接触角。

3. 積分形（$x(0)=x_0$）

変数分離すると：

$$4\big[\mu_2 L+(\mu_1-\mu_2)x\big]\,dx = r\sigma\cos\theta\,dt$$

両辺を $x_0 \to x$、$0\to t$ で積分：

$$\mu_2 L (x-x_0) + \frac{\mu_1-\mu_2}{2}\left(x^2-x_0^2\right) = \frac{r\sigma\cos\theta}{4}\,t$$

4. 主結果：$x=F(t)$

$$x(t) = \frac{-\mu_2 L + \sqrt{\big(\mu_2 L+(\mu_1-\mu_2)x_0\big)^2 + \dfrac{(\mu_1-\mu_2)\,r\sigma\cos\theta}{2}\,t}}{\mu_1-\mu_2}$$

5. Sanity check

$t=0$ で $x(0)=x_0$ に一致。$\mu_2\to0$（defending側が空気などの低粘性流体）の極限では、古典的な Lucas–Washburn方程式（$x\propto\sqrt{t}$）に一致する。

6. Validationでの使い方

VOFソルバにこのセットアップを与えて数値計算し、$x(t)$ を解析解と時系列で直接比較する。誤差が閾値内なら Viscous Fingering 本編（多孔質構造）へ進む前のV&V（Verification & Validation）の1ステップとして使える。
