FKeX — 開発ドキュメント

最終更新：2026-07-08（M6 完了時点）／初版：2026-07-07

FKeX（仮名）は AMReX ベースの非圧縮二相流ソルバ。VOF 法にサブグリッド解像の界面表現（fine-grid interface closure）を組み合わせた手法を、AMReX のデータ構造と線形ソルバの上にクリーンルームで新規実装する。研究用 Fortran ソルバ（FK3）の後継†1。

このページは開発ドキュメントの入口（インデックス）。実装の節目（マイルストーン）ごとに更新する。設計判断の深掘りと検証の生データは、上部ナビの設計判断・検証台帳の各ページへ。

これは何か

一言でいえば「旧 Fortran ソルバ（FK3）で検証済みの手法を、公開・保守・拡張に耐える基盤の上で作り直す」プロジェクト。

目的：気液二相流の表面張力計算を、界面近傍だけ細かいサブグリッドで解像するクロージャ（FGVT 系 + fine-grid balanced CSF）で高精度化する。この手法自体は既存 Fortran 実装（FK3）で検証済みで、それを C++17 / AMReX に移す。

設計原則は次の 4 つ。単なる移植ではなく「新規に書き下ろす」点が特徴で、旧コードは答え合わせの基準（実行オラクル）としてだけ使う。

  1. 依存は AMReX 本体のみ（incflo / IAMR / AMReX-Hydro からのコード借用なし）。ライセンス・出自を明快に保つ。
  2. クリーンルーム実装 — 旧コードの翻訳ではなく、数式仕様ノートから書き下ろす。旧コードは実行オラクル（数値突合の基準）としてのみ使う。
  3. 変数名・慣用は AMReX 基準（MultiFab / ParmParse / plotfile エコシステムにネイティブに乗る）。
  4. カーネルは初日から MFIter + ParallelFor(Array4) 規律（将来の GPU 対応の保険）。

アーキテクチャ骨子

設計の中心は下図の二重格子構造。流れ場（速度・圧力）は粗い一様格子で解き、界面の VOF は同じ領域を 2 倍細分したサブグリッドで持つ。両格子は同じ箱割り・同じ DistributionMapping なので、粗細間のデータのやり取りが各 rank の中で完結する。

要素実装
格子単一レベル一様格子（AMR は将来）。MAC スタガード配置
速度面センター MultiFab（Array<MultiFab,AMREX_SPACEDIM>）
VOF・圧力・物性セルセンター MultiFab
サブグリッドrefine(BoxArray, 2) ＋ 粗格子と同一の DistributionMapping を持つ細レベル MultiFab 群。粗箱 i と細箱 i が常に同一 rank ＝ 粗細のバルク転送がローカルに閉じる（図1。判断の経緯は設計判断ページ）

M0 完了メモ（2026-07-07）

物理演算を入れる前に、データ構造とビルドの骨格を固めた段階。

  • できたもの：粗＋refine(2) 細（同一 DistributionMapping）の全 12 MultiFab（ghost 4）、静止液滴 IC（4×4 サブセルサンプリング。VOF 積分の相対誤差＝粗 1.9e-3／細 7.5e-5 vs πR²）、2 レベル plotfile、ゴースト NaN 検査モード、共有面一貫性チェック（面型 MF を OverrideSync と突合＝全方向で厳密 0）、ケース表 CSV→inputs 生成、WSL 同期・ビルドスクリプト一式。リリース／DEBUG 両ビルド・複数箱（max_grid_size 32/16）スモーク green。
  • ビルドは 1 コマンド：bash _localdev/fkex/wsl/build.sh（同期→AMReX 26.07 取得→make→スモーク→plotfile 確認）。
環境の罠（対策済み・スクリプトに内蔵）：(1) wsl.exe は Windows 側 CWD を継承して失敗する → 全呼び出しに --cd '~'。(2) Git Bash の MSYS パス変換が WSL 向け引数を化かす → MSYS_NO_PATHCONV=1。(3) AMReX 26.07 は既定で Fortran モジュールをビルドする → BL_NO_FORT=TRUE（非 Fortran 方針とも整合）。ビルドフラグ変更時は tmp_build_dir を削除してから再 make。

M1 完了メモ（2026-07-07）

解析的に与えた速度場（規定速度場）で VOF 移流だけを単体で動かし、標準ベンチマークで精度を確認した段階。

  • 中身：PLIC（Youngs 3^DIM コーナー勾配法線＋解析 alpha＝Scardovelli–Zaleski 2000/Lehmann–Gekle の閉形式・反復なし）、方向分割 EI（Eulerian 陰）スイープ＋最終発散整合補正（Scapin et al. 2020 系譜）、6 段回転パリンドロームのスイープ順（2D は 2 段）。カーネルは全て Array4+Box の自由関数（サブグリッドにそのまま載る）。数式仕様ノート doc/vofAdvection.md 先行のクリーンルーム実装。
  • 用語注記：「EI（Eulerian Implicit）」は split-VOF 文献の形式の呼称で、時間陰解法ではない。全演算は陽的（線形ソルバ・反復なし）。doc/vofAdvection.md に注記済み。
検証：質量保存 rel ~1e-15（ゲート 1e-12）／Rider–Kothe 渦の反転 L1=8.8e-3（64²）・3.9e-3（128²）＝旧ソルバ記録値と同水準／Zalesak 3.5e-2（100²）＝文献 PLIC と同オーダー／箱分割不変性 OK。
発見 2 つ：(1) 参照ソルバの分裂法は通説の Weymouth–Yue 補正ではなく EI＋最終補正だった（ノート作成フェーズで判明・仕様を訂正）。(2) 規定速度場は節点ストリーム関数の差分で組まないと離散 MAC 発散が O(h²) 残り、質量ゲート 1e-12 を割る（点評価は不可）。

M2 完了メモ（2026-07-07）

VOF をいったん脇に置き、単相の Navier–Stokes 時間積分（図2 の②④）と MAC 射影を検証した段階。

  • 中身：単相 fractional step（Lie 分割・前進 Euler・射影はステップ末 1 回・非増分 projection-1＝圧力は毎ステップ置換）。MAC 射影は MLABecLaplacian+MLMG の薄ラッパ（φ=Δt·p′ 規約、β は面配列＝M3 で 1/ρ に差し替わる設計）。運動量移流は保存形（質量 M・運動量 P を方向分割で flux 更新し u=P/M、QUICK 面値）、粘性は応力発散形の陽解法。
検証：射影自己検証（manufactured solution）＝配線 3.3e-16／解析 RHS で収束次数 1.99／射影の恒等性・冪等性 1.4e-14。Taylor–Green の KE 減衰＝解析 e−4k²νt 比 0.975/0.993/0.998（32²/64²/128²、単調 2 次接近）、動圧振幅誤差 1.3%。射影後 max|div(u)|<1e-11 全ステップ。M1 ケース回帰＝ビット一致。
発見：参照ソルバの圧力は「増分累積」ではなく毎ステップ置換（非増分 Chorin projection-1、予測子に ∇p 無し）— 仕様書の当初表記を訂正。参照ソルバの陽的粘性 dt 条件は係数設定で実質無効化されていた＝FKeX は真の条件を既定化（意図的差分として記録）。

M3 完了メモ（2026-07-08）

二相・高密度比に踏み込んだ段階。密度比 1000:1 でも界面で運動量が破綻しない「整合移流」が主役（表面張力はまだ入れない）。

  • 中身：二相・変密度（密度比 1000:1、張力なし）。整合移流＝c と質量 M・運動量 P が同一の PLIC swept 体積（液/気分割）を共有し、G=ρl·Sl＋ρg·Sg、H=G·qQUICK、u=P/M。面密度は移流質量 M/V で一貫更新し、粘性の除算・圧力補正・射影 β=1/ρf が全て同一実体（高密度比ロバスト性の生命線）。
  • 設計決定：整合経路の VOF 更新は参照実装に忠実（スイープ毎 EI＋クリップ・最終補正なし）とし、plain 経路（M1）との差は質量ドリフト・クリップ量の常時診断で監視する方式に確定。
検証：密度比 1000 液滴の一様並進（固定点テスト）＝速度誤差が厳密 0（ビット一致の固定点）・div=0・保存 ~1e-16。変係数 β の manufactured solution＝2 次収束（1.996/1.999）。クロスコード frozen-RHS＝参照ソルバから静止液滴（Laplace 構成・β 跳び 10³）の圧力方程式 RHS・β・解をダンプし、FKeX の離散作用素・MLMG 解と突合 → 作用素恒等 5.8e-9（＝参照側ソルバ残差水準）・再 solve 一致 rel 3.2e-10。旧マイルストーン回帰は全てビット一致。

M4 完了メモ（2026-07-08）

表面張力（粗格子の balanced CSF）が入り、粗格子版パイプラインが全段そろった段階。初の非周期境界（壁）もここで導入。

  • 中身：height-function 曲率（3×3×7）＋κ 拡張＋balanced-force CSF 面力。検証専用の exact-κ モード、壁 BC（自由すべり）、毛管 dt 条件。
検証（詳細は検証台帳）：exact-κ の静止液滴で balanced-force 恒等が machine-zero（settled 1.5e-14）・Laplace 圧 Δp*=1.00000000。HF 曲率では旧ソルバのアンカーと Δp* が 5 桁一致、スプリアス・カレントは同水準以下。毛管波の減衰は Prosperetti 厳密解に対し RMS 0.0015（旧ソルバ記録 0.0081 の約 1/5）。全回帰ビット一致。

M5 完了メモ（2026-07-08）

二重格子の本領＝サブグリッド移流が入った段階。「細格子 VOF が一次状態・粗 c は平均の導出量」というアーキテクチャがここで実体化した。

  • 中身：粗→細速度補間 3 方式（linear／ψ-curl＝厳密 div-free・2D 既定／multilinear＝3D 既定・非 div-free）、細レベル PLIC 移流（M1 カーネル再利用＋HF 整合法線上書き）、nsub=2 厳密タイル幾何の整合運動量集約（横断 CV＝本物の細半行・½係数なし）。
検証（詳細は検証台帳）：vortex 細解像 L1=1.89e-3＝同じ粗格子の plain PLIC（8.76e-3）の 4.6 倍改善で、2 倍細かい plain 128²（5.0e-3）をも上回る。固定点テストが全 3 補間方式でビット厳密成立（集約幾何の直接証明）。frozen サブ場クロスコード全 PASS。回帰全ビット一致。
重要発見：massfix 後に u=P/M を再除算すると 1ulp の丸めが播種され、QUICK×密度比 1000（無粘性）で毎ステップ ×1.1 に増幅されて発散する。P/M は数学的に不変なので u 据え置きが浮動小数点的に正しい実装（数式ノートに修正を記録）。

M6 完了メモ（2026-07-08）＋補間方式の整理

手法の核＝サブグリッド上で評価した表面張力を粗格子へ整合的に集約する経路が入った段階（公開版では要約に留める）。

  • 中身：曲率源は「細格子で直接評価」「粗格子から放送」の 2 方式をノブ化（champion 選定は M7 の動的検証で決定＝保留中）。検証専用の厳密曲率モードで集約経路の恒等性を分離測定。
検証（詳細は検証台帳）：厳密曲率で恒等が machine-zero（5.2e-21／1.9e-13・Δp*=1）＝集約が力の釣合いを一切損なわない。粗放送は旧ソルバと Δp* 6 桁一致。毛管波も旧ソルバ記録の 1/2.7。旧ソルバで知られていた細曲率の settled 飽和（|U|≈0.98）は FKeX では再現せず、1e-8 級の有界床に留まる（機構調査済み）。
補間方式の整理（ユーザ裁定）：粗→細速度補間は linear／multilinear の 2 方式に確定（multilinear＝champion・全次元）。ψ-curl は削除。champion 系基準値は multilinear で再取得済み。あわせて旧ソルバの参照アンカーを欠陥是正の再走で全面更新し、差の因子分離（旧ソルバ側の補助機構 2 つが合計 −65% の精度コスト）まで完了。
