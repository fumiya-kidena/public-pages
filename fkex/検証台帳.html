検証台帳

最終更新：2026-07-08（M6 追記）

マイルストーンごとの検証ケースの詳細設定・ゲート・実測値・そこから何がわかったかの台帳。本体（開発ドキュメント）には要約のみを載せ、詳細はここに集約する。各ケースの inputs はリポジトリの input/<case>（ケース表 case/case.csv＋case/genInput.py から生成）に同梱＝再現可能。

検証の考え方：三層オラクル

クリーンルーム実装（旧コードを見ずに数式仕様から書き下ろす方式）では、「書けたつもり」を潰す答え合わせの基準（オラクル）が生命線になる。FKeX では性格の違う 3 層を重ねて使う：解析解・文献値で物理として正しいかを、旧ソルバ（FK3）とのトレンド突合で精度水準が先代と揃っているかを、frozen-field 突合で「同じ計算をしているか」をカーネル単位・機械精度で確かめる。下の各マイルストーンのゲートは、この 3 層のどれかに対応している。

M0 — データ骨格スモーク（2026-07-07）

物理を入れる前に、器（データ骨格）だけを検査した段階。

設定静止液滴 IC（[0,1]²、円 R=0.25 中央、64²・細 128²、max_grid_size=32＝4箱）。物理演算なし
ゲートと実測共有面一貫性（面型 MF vs OverrideSync owner 値）＝全方向で厳密 0／2 レベル plotfile 構造正常／VOF 積分 vs πR²＝粗 1.9e-3・細 7.5e-5（4×4 サブセルサンプリングの理論水準）
わかったこと：粗＋refine(2) 細（同一 DistributionMapping）のデータ骨格と、面型 MultiFab の共有面所有の扱いが健全。ゴースト NaN 検査モードの土台も機能。

M1 — 純移流 VOF（2026-07-07）

解析的に与えた速度場（規定速度場）で VOF 移流だけを動かし、標準ベンチマーク 2 種で精度を測った。

ケース詳細設定

vortexRider–Kothe 単一渦（時間反転 cos(πt/T)、T=4）、旧ソルバのオラクル run と同条件（円 R=0.6、64²/128²）、fixed dt=1/64（CFL 0.25）、トラフ判定＝t∈[3.9,4.1] の最小 L1（旧ソルバと同じ読み方）
ゲート実測
質量保存（全ステップ）rel 1.4e-15（ゲート 1e-12）
vortex 反転 L18.76e-3（64²）＝旧ソルバ記録 1.06e-2 の 0.83×／3.90e-3（128²）＝記録 5.01e-3 の 0.78×
zalesak 1 回転 L13.52e-2（Rudman 1997 の PLIC ≈1.1e-2 と同オーダー。原典の格子・CFL 未照合のため定性判定）
箱分割不変性max_grid_size 変更で結果一致
わかったこと：
  • PLIC（Youngs 法線＋解析 alpha 閉形式）と方向分割 EI スイープ＋最終発散整合補正の組が正しく実装できており、精度は旧ソルバと同水準（やや良い）。
  • 参照ソルバの分裂法は通説の Weymouth–Yue ではなく EI＋最終補正（Scapin et al. 2020 系譜）だった＝移植仕様の誤記を発見・訂正。
  • 質量保存 1e-12 級は「速度場が離散的に div-free」が前提。規定速度を面中心の点評価で作ると O(h²) の離散発散が残ってゲートが割れる → 節点ストリーム関数の差分で構成（今後の全ケースに適用される教訓）。
⚠ vortex の旧ソルバ記録値は「ハーネス欠陥フラグ付き run」由来＝倍半分のトレンドアンカー。タイトな帯にするには旧ソルバの再走が必要（open）。

M2 — 単相 fractional step＋MAC 射影（2026-07-07）

VOF を切り離し、単相 Navier–Stokes の時間積分と圧力射影を「ソルバ単体の自己検証」と「解析解つきの流れ」の両面から検証した。

taylorgreenTaylor–Green 渦：[0,1]² 二重周期、N=32/64/128、ν=0.018257（旧ソルバのオラクル run と同値。テンプレ既定 ν=0.01 とは異なる点に注意）、U0=1、k=2π、t=1 まで。KE=面速度のセル中心平均で Σ½ρ|u|²ΔV
ゲート実測

TG KE 減衰 vs 解析 e−4k²νt比 0.975（32²）／0.993（64²）／0.998（128²）＝単調 2 次接近。動圧振幅誤差 1.3%

わかったこと：
  • MLABecLaplacian＋MLMG の MAC 射影が正しく配線され理論次数（2 次）で収束。
  • 参照ソルバの時間積分の実体＝Lie 分割・前進 Euler・射影はステップ末 1 回・非増分 projection-1（圧力は毎ステップ置換） — 仕様書の当初想定「圧力増分の累積」は誤りで訂正。
  • 参照ソルバの陽的粘性 dt 条件は係数設定（cfl2=1e5）で実質無効だった → FKeX は真の条件を既定化（意図的差分）。
  • 運動量移流（保存形 M/P＋QUICK）は一様場で厳密に定数を保つ＝M3 の固定点テストの土台。

M3 — 二相・変密度（2026-07-08）

二相・高密度比（1000:1）での整合移流を、固定点テスト・manufactured solution・クロスコード突合（三層オラクルの③）の三方向から検証した。

dropadvect[0,1]² 二重周期、64²、円滴 R=0.2 中央、ρl/ρg=1000/1、μ 両相 0（粘性段 off）、σ=0、初期一様速度 (U0,0)=(1,0)、1 横断 T=1（≈427 step、CFL 0.15）。移流＋射影を毎ステップ実行（射影も不動点主張に含む）
PROJTEST4/5変係数 β=1+0.5sin(2πx)sin(2πy) の manufactured solution（配線＋収束次数）
projfrozenfrozen-RHS：参照ソルバの専用コピー（ダンプ文追加・環境変数ガード）で静止液滴（Laplace 構成）σ=1・密度比 1000・64²・単一 rank・1 step の圧力方程式 RHS・面密度・解をテキストダンプ → FKeX が (1) 自前離散作用素をダンプ解に適用して恒等確認（ゲージ不要）(2) 再 solve して平均引き後比較
ゲート実測
並進固定点 max|u−U0|/U0厳密 0（ビット一致）。div=0
保存（この流れでは厳密が成立する特例）Σc 4.4e-16／ΣM 6.7e-16／ΣP 4.5e-16／クリップ累計 3e-18
変係数自己検証配線 1.9e-13／収束次数 1.996・1.999
frozen-RHS作用素恒等 5.8e-9（＝参照側ソルバ到達残差水準）／再 solve 一致 rel 3.2e-10（numpy 独立検算済）。dp 振幅 ≈σ/R（Laplace 整合）、β 跳び 10³

わかったこと：
  • 質量 flux と運動量 flux の整合が厳密：一様速度は密度場（比 1000）に依らず離散的な固定点＝界面での偽加速ゼロがビットレベルで成立（整合が少しでも壊れているとここに現れる）。
  • 参照ソルバと FKeX の圧力方程式は同一の離散作用素：ソルバ（ILU-BiCGSTAB vs MLMG）が違っても同じ解を返すことをコード横断で確認 → 以後、二相の挙動差が出たらソルバ層は容疑から除外できる。
  • 整合経路（運動量つき）の VOF 更新の実体＝スイープ毎 EI＋クリップ・最終補正なし（plain 経路とは別物。移流速度がスイープ毎に u=P/M で変わるため共通 div-free 前提の最終補正は根拠を失う、という構造的理由）。一般流では O(Δt) 級の質量ドリフトが正常挙動 → ドリフト・クリップ量を常時診断し、ケースごとに plain 経路と並記する運用に。
  • 参照ソルバ側の発見：粘性 μ blend は prop 層の算術ではなく粘性段内の調和 blend（ハードコード）が実体／整合経路の D2 診断は移流前内挿を使う（意図要確認）。

M4 — 粗 B-CSF（表面張力）（2026-07-08）

表面張力が入った段階。balanced-force が本当に「恒等」になっているかを、曲率を厳密値に固定した対照実験（exact-κ）で切り分けるのが主眼。初の非周期境界（壁）もここで導入。

ケース詳細設定
sdrop_ex / sdrop_hf静止液滴：2D 64²（Δ=1/64）、1×1 領域中心に R=0.25 液滴、σ=1、ρl/ρg=1/1e-3、μl/μg=0.1/1e-3、無重力、遠方場 BC（openfar）、c 初期化は厳密（解析円とセルの重なり）。曲率＝exact（定数 κ=1/R=4、検証専用）と HF（3×3×7）の 2 構成。2 モード測定：impulsive＝dt 固定 1e-11×2 step（初期離散インバランス）／settled＝物理 dt 制御で t≈τ=ρlR²/μl=0.625（自己維持スプリアス流）。指標：|U*|=|U|max/(σ/μl)、Δp*=(p̄in−p̄out)/(σ/R)（in: c>0.99、out: c<0.01＝CSF 力帯除外）
capwave / capwave_inv毛管波：領域 1×2、64×128、x 周期・y 壁（自由すべり un=0、射影は Dirichlet-p 壁＝D13）、界面 y=a0·cos(kx)（a0=0.01、k=2π）静止開始。matched 物性 ρ 両相=1、μ 両相=0.018257（La=σρλ/μ²=3000）、σ=1。毛管律速 dt。振幅診断＝列液高の固定第 1 列符号付き振幅（旧ソルバと同定義）。無粘性変種は μ=0
ゲート実測
exact-κ（balanced-force 恒等）impulsive |U*|=5.9e-21／settled 1.46e-14（machine-zero 級）、Δp*=1.00000000（両時点）
HF κ vs 旧ソルバ S3 アンカーimpulsive 2.83e-13（アンカー 1.45e-13 の 2 倍・3 倍帯内）／settled 1.43e-11（アンカー 4.4e-11 より良）。Δp*=1.00189/1.00179＝アンカーと 5 桁一致
capwave 粘性 RMS vs Prosperetti(1981)0.001466（窓 τ≤25。ゲート ≤0.016＝旧記録 0.0081 の 2 倍帯）。エネルギー注入なし（max â=1.000000）
capwave 無粘性振幅非成長（max â=1.000000）＝注入なしの定性確認
回帰・箱分割vortex／TG／PROJTEST1–5／dropadvect 全て基準値と一致（ビット一致含む）、multibox OK
わかったこと：
  • balanced-force が離散恒等として成立：κ を厳密値にすると面力 σκ(∇c)f が厳密な離散勾配になり射影が完全吸収 → スプリアス流 machine-zero。成立条件（①面力の ∇c＝圧力勾配と同一の 2 点面ステンシル、②力を割る ρf＝射影 β の同一実体、③同一面）が正しく組めたことの直接証明。
  • HF 曲率は旧ソルバと同じ離散に到達：Δp* が 5 桁一致＝曲率・力・射影の離散が実質同一。スプリアスがやや良いのはソルバ許容誤差（1e-11 vs 旧 1e-8）の寄与とみられる。
  • 毛管波 RMS が旧ソルバ記録の約 1/5（0.0015 vs 0.0081）：明確に良い方向だが要因は未分離（ソルバ許容誤差・曲率交差微分の式の差・dt 制御が候補）。
  • 初の非周期 BC（壁）が設計どおり機能（境界面 valid への法線直接代入）。射影の壁 BC は参照忠実の Dirichlet-p を採用。
  • 旧ソルバ側の発見：HF 交差微分の分母に誤記（均一格子では無影響・FKeX は正しい式＝ストレッチ格子では両者が一致しなくなる点に将来注意）／未初期化フラグの潜在 UB。
⚠ 暫定事項：HF 系のゲート帯は kappa_source（fine|coarse）未決着前提の「アンカー×3」帯。capwave RMS の評価窓は今回 τ≤25 で固定（旧側台帳の窓は非明記＝厳密比較には旧側の再走が要る）。

M5 — FGVT サブグリッド移流（2026-07-08）

二重格子の本領。細格子 VOF（一次状態）を動かし、質量・運動量を粗格子へ厳密に集約する段階。固定点テストと frozen 突合で「幾何が厳密か」を機械精度で確かめた。

ケース詳細設定
vortex_fgvt / zalesak_fgvtM1 と同一ハーネスのサブ解像版（粗 64²＋細 128²、vortex は 128²＋細 256² も）。補間=psi_curl（2D 既定）、比較用に linear／multilinear。dt は細 CFL 対応。トラフ読み・質量・細 div-free ノルムを毎ステップ診断
dropadvect_fgvtM3 の固定点テストの FGVT 版（ρl/ρg=1000 一様並進・854 step）。全 3 補間方式で実行
subgrid_frozenサブ場 frozen-field：①補間直後の粗入力＋細出力 MAC 場 ②移流ステージ完了後の細分率・集約 CV 質量/運動量（固定掃引順で両コード係合・2 方式×2 流れ）。FKeX 側は①補間突合 ②フルステージ再生突合
ゲート実測
vortex_fgvt（psi_curl）粗 c 復帰 L1=1.891e-3／細 2.524e-3 ＝ plain 64²（8.76e-3）の 4.6 倍改善・plain 128²（5.0e-3）も上回る。128²+細256² で 9.33e-4/1.53e-3 とトレンド継続
zalesak_fgvt細 L1=1.363e-2 ＝ plain 100²（3.52e-2）の 2.6 倍改善
dropadvect_fgvt（固定点）全 3 補間方式で max|u−U0|=0.0（ビット厳密）・保存 ~1e-16
質量・div-freepsi_curl/linear＝質量 rel ~1e-15・細 div-free 4.4e-16（machine zero）。multilinear＝div-free 1.9e-2・質量 3.6e-6 LOGGED（非 div-free、最終補正が load-bearing＝記録どおり）
frozen サブ場クロスコード補間：linear 1.5e-32（実質ビット一致）／psi_curl 1.4e-14。フルステージ再生：c_fine 7.3e-15・CV 質量 ~1e-16・横断運動量のみ rel ~5e-10（FP 環境床＝M3 の帯と同水準）
回帰・箱分割M1〜M4 全て基準値一致（ビット一致含む）、multibox OK
わかったこと：
  • FGVT の精度利得が FKeX でも成立：同じ粗格子で plain PLIC の 4.6 倍、2 倍細かい plain をも上回る（「サブ格子は細格子相当以上」の実証。Rudman 1998 の ~4× 報告と整合）。
  • 補間方式の序列が記録どおり再現：ψ-curl ◎／linear は階段横断で劣る／multilinear は補正が load-bearing — 「2D=ψ-curl、3D=multilinear」の champion 使い分けの根拠を確認。
  • 整合集約の幾何が厳密：固定点が全方式でビット成立＝横断 CV の細半行タイル・pre-state の 8 細セル体積平均・代表面風上の組が正しい。
  • FP 増幅の発見：massfix 後の u=P/M 再除算は 1ulp を播種し QUICK が指数増幅（無粘性・密度比 1000 で発散を実測）。u 据え置き（P/M 不変の FP 恒等形）で解決。参照ソルバも字義どおりなら同じ潜在問題＝要確認。
  • 参照ソルバの FGVT アンカーは欠陥 run 由来＝修正済みハーネスでは大幅に下回るのが正常 → 判定は「同粗格子の plain を超える」トレンドゲートへ。
⚠ 参照ソルバ側の FGVT vortex 再走（是正ハーネス）は M1 と共有の open item のまま。

M6 — サブグリッド表面張力（FGB-CSF）（2026-07-08）※公開版は要約

  • 旧ソルバの細曲率 settled 飽和は実装/環境固有の可能性が高い（FKeX では再現せず有界床）＝手法の主経路にとって良い知らせ。
