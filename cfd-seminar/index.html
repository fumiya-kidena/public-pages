cfd-seminar まとめ

最終更新: 2026-07-08

Fortranベースの、ごくシンプルな2次元非圧縮CFDコード。速度をセルの面・圧力をセル中心に置くMAC（スタガード）格子[4]の上で、Fractional Step法（射影法）[3]で解く。

ソースは GitHubリポジトリ（MITライセンス）にある。

このテキストは wrk/ のひな形（重要な計算部分が空欄）を、実際に自分の手で埋めながら 2次元CFDコードを完成させていくための手順書。

進め方

  1. 初期条件 — 格子・物性設定・ビルド方法・可視化（Fortranの基礎練習を兼ねる）
  2. 移流項 — 運動量方程式の移流項を離散化する（境界条件は完成形を与える）
  3. 粘性項 — 拡散項（粘性）を追加する
  4. 境界条件 — lid-driven cavity に切り替え、壁の境界条件（ゴーストセル）を自分で書く
  5. 圧力Poisson — 圧力を求めて速度を非圧縮に補正する（ここで初めて cavity らしい渦ができる）
  6. 移流項の改良 — 素朴な移流項が高いセルPeclet数で破綻する様子を見て、改良の方向を考える

ディレクトリ構成

cfd-seminar/
├── src/               # 完成形（独立したmakefile・config.csv）
├── wrk/               # 自習用未成コード（重要部分が空欄のひな形、src/と同じ構成）
├── post/              # 後処理・可視化スクリプト（Python）
├── data/              # シミュレーション出力（.gitignore対象）
└── docs/              # まとめ資料一式（GitHub Pagesで公開）
    ├── index.html     #   まとめの入口（このページ）
    ├── setup.html …   #   各ステップのページ（setup / intro / advection / …）
    └── assets/        #   共有CSS・JS・画像（assets/img/）

src/は動作確認・検証済みの完成形、wrk/は同じファイル構成で重要な計算部分が 空欄になっているひな形（ビルド方法は初期条件を参照）。
